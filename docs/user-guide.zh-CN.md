## 1. 打开程序

由持有仓库的人执行：

```bash
npm install
npm run dev -- --host
```

- 在同一台电脑上打开 <http://localhost:5173>。
- 在同一 Wi-Fi 下的手机或 iPad 上，打开终端显示的 `Network:` 地址（例如 `http://192.168.1.20:5173`）。

任何现代浏览器均可（Chrome、Edge、Safari、Firefox）。

## 2. 选择题目

首页把题目分为两组：

- **Cambridge IGCSE Chemistry 0620 · Paper 5 Practical Test**
- **Cambridge International AS & A Level Chemistry 9701 · Paper 3**

每张卡片显示考试季、总分和对未知物的中性描述（不会透露答案）。点击卡片即可开始。

## 3. 考试界面

| 区域 | 说明 |
|---|---|
| **顶栏** | ← 返回题目列表 · 试卷及题号 · ⏱ 已用时间 · 观察文字开关（*Observation text*）· 交卷（**Finish**） |
| **试剂架**（Reagents） | 本题实验台上的试剂瓶，与机密说明中所列一致 |
| **样品区**（Samples） | 未知物（如 *solid E*、*FA 7*）及其容器 |
| **试管架**（Rack） | 你的试管、沸腾管、硬质玻璃试管和滤纸。用 **+ test-tube**、**+ boiling tube**、**+ hard-glass tube** 取一支干净的 |
| **仪器**（Apparatus） | 本生灯、湿润红色／蓝色石蕊试纸、石灰水、带火星木条、燃着的木条、焰色测试金属丝、通用指示剂试纸、漏斗、洗瓶、废液缸 |
| **操作面板** | 选中试管后出现：显示体积和温度、可进行的操作，以及上一步操作的结果 |
| **试卷／实验笔记**（Question paper / Lab notebook） | 带答题位置的题目；以及所有操作的记录和草稿栏 |

**实验台上的时间会持续流逝。** 大约每两秒推进一次模拟时间：沉淀会沉降、气泡逐渐停止、热试管会冷却、氢氧化亚铁表面会慢慢变棕。隔一会儿再看看试管——就像在真实实验室一样。

### 观察文字开关（*Observation text*）

默认关闭。真实考试中没有人告诉你看到了什么，所以平时只会显示试管的**画面**（颜色、沉淀、气泡、气体颜色、冷凝水、石蕊或石灰水的结果）。打开开关后，会同时显示引擎对每个结果的文字描述——适合学习术语，或屏幕上颜色难以判断时使用。

## 4. 在实验台上操作

基本流程是 **选中试管 → 选择操作**。

1. **点击试管**选中它（再点一次或点 ✕ 取消选中）。
2. **点击试剂瓶**加入该试剂，或**点击仪器**对选中的试管使用，或使用**操作面板**中的按钮。

### 加入试剂

点击试剂瓶会打开滴管面板。如果尚未选中试管，需要先选择一支——已有的试管，或一支**新的**试管／沸腾管／硬质玻璃试管。

- 溶液：**Add 1 drop**（1 滴）、*a few drops (5)*（几滴，即 5 滴）、*0.5 / 1 / 2 / 4 / 5 cm depth*（液面深度），或自行输入数量，单位为 **cm depth**（深度）或 **cm³**。
- 固体（如锌粉、MnO₂）：*small spatula measure*（小半药匙）或 *spatula measure*（一药匙）。
- 片状物（铝箔、镁带）：*Add one piece*（加一片）。

面板会保持打开，放大显示试管，并给出每次加入后的结果，方便**逐滴**加入并观察。"逐滴加入，然后过量"（dropwise, then in excess）的意思是：每次加一滴并观察，持续加入直到不再有变化，然后再多加几厘米深度。

面板会显示试管中已有的液体（cm³ 及约 cm 深度）。一支试管约可容纳 14 cm³（约 10 cm 深），沸腾管约 48 cm³。加入超过容量会溢出。

### 操作面板中的操作

| 操作 | 说明 |
|---|---|
| **Pour into… / Transfer solid…**（倒入／转移固体） | 选择目标试管（或新试管），再选 *1 / 2 / 4 cm depth*、*about half*（约一半）或 *all*（全部）；固体可选药匙量、一半或全部 |
| **Divide…**（分装） | 把内容物平均分到若干支新的干净沸腾管和试管中——对应题目中的 "divide solution X into four portions" |
| **Heat…**（加热） | 液体：*Warm gently*（温和加热）或 *Heat to boiling*（加热至沸腾）。固体：*Heat gently*（缓慢加热）或 *Heat strongly*（强热）。时间可选 10–90 秒 |
| **Shake**（振荡） | 混合并帮助固体溶解 |
| **Leave to stand…**（静置） | 30 秒至 5 分钟——用于需要时间的变化（如 "leave to stand for two minutes"） |
| **Test gas…**（检验气体） | 在试管口检验：湿润红色／蓝色石蕊试纸、石灰水、带火星木条、燃着的木条、酸化 KMnO₄、酸化重铬酸盐(VI) 试纸 |
| **Insert / Remove stopper**（塞上／取下塞子） | 振荡前塞上塞子；切勿加热塞着塞子的试管 |
| **Empty**（倒掉） | 把内容物倒入废液缸；若不清洗，管壁会残留液膜 |
| **Rinse**（清洗） | 用蒸馏水冲洗试管，避免残留物带入下一个测试 |
| **Remove tube**（移走试管） | 把试管架上的试管拿走（样品不能移走） |

### 仪器

仪器按钮作用于**当前选中**的试管：

- **本生灯**（Bunsen burner）——与 *Heat…* 相同。
- **湿润红色／蓝色石蕊试纸、石灰水、带火星／燃着的木条**——检验**此刻**试管口的气体。气体逸散很快，所以要在反应进行**期间**或刚加热后立即检验。
- **焰色测试金属丝**（Flame test wire）——对试管内容物（固体或溶液）做焰色测试。
- **通用指示剂试纸**（Universal indicator paper）——测溶液的大致 pH。
- **漏斗**（Filter funnel）——过滤混合物：滤液进入一支新试管，滤渣留在试管架上的滤纸上。
- **洗瓶**（Rinse）和**废液缸**（Empty into waste）——同上。

试管架最多放 18 个容器。可把试管倒空并清洗后重复使用，或移走不再需要的试管。

### 加热固体

强热固体需要使用**硬质玻璃试管**（或沸腾管）。注意观察熔化、颜色变化（有些固体热时和冷却后颜色不同）、试管口附近的冷凝水，以及有颜色的气体或蒸气。加热后静置可观察冷却后的样子。

## 5. 填写答案

打开**试卷**（电脑：右侧的 *Question paper* 标签；手机：底部的 **📄 Paper**）。试卷沿用原题版式：引言，然后是各小题、分值及答题位置——答题线、测试与观察表格，或带标签的填空栏。

- 按评分标准的写法作答：同时写出颜色**和**状态（例如 "white precipitate, soluble in excess giving a colourless solution"），以及 "effervescence"、"damp red litmus turns blue" 等。
- 记录你**看到**的现象，而不是你预期的现象。如果在实验台上操作出错，用一支干净的试管重做。
- **实验笔记**（Lab notebook）按时间和试管列出每一步操作；其他内容可写在 *Rough notes*（草稿）栏。

答案会在输入时自动保存。

## 6. 交卷与自我评分

点击 **Finish**（顶栏或试卷底部）并确认。自我评分页面会为每一小题显示：

- 题目（点击 *Question* 展开）；
- **你的答案**（Your answer）；
- 官方**评分标准**（Mark scheme）；
- **监考员结果（模拟）**（Supervisor's results (simulation)）——严格按题目步骤操作时本模拟产生的结果，相当于真实考试随答卷寄出的监考员报告；
- 一排分数按钮（0 至满分），用来给自己打分。

总分显示在右上角。页面底部可查看**未知物是什么**（来自机密说明），以及**你在实验室中的全部操作**及每一步的观察——可与自己写的答案对照。

之后可选择 **Try this question again**（清除本题的答案、笔记和分数，并重新开始一个新的实验台）或 **Choose another question**（选择其他题目）。

请诚实评分：只有当你的答案包含评分标准中的要点时才给分。如果监考员结果与你的观察不同，请在操作记录中找出你的步骤与题目不同之处。

## 7. 规范操作——以及不规范会怎样

引擎只知道每支试管里有什么，所以典型的错误操作会得到与真实实验室相同的结果：

| 如果你…… | 会看到…… |
|---|---|
| 加 AgNO₃ 前用稀 **HCl** 酸化 | 即使样品不含氯离子也出现白色沉淀（AgCl）——应使用稀**硝酸** |
| 对碳酸盐加 Ba²⁺ 或 Ag⁺ 前忘记酸化 | 加硝酸钡出现白色沉淀（误判为"硫酸根"），加硝酸银出现沉淀 |
| 重用未清洗的试管 | 上一次测试的残留，例如氯离子令 AgNO₃ 变浑浊 |
| 用自来水代替蒸馏水 | 加硝酸银时略显浑浊 |
| 向已酸化的溶液加 NaOH | 最初几滴只是中和酸，沉淀稍后才出现 |
| 一次倒入大量过量 NaOH（例如对 Al³⁺ 或 Zn²⁺） | 沉淀只出现一瞬间，甚至看不到——应**逐滴**加入 |
| 试管冷却后才检验氨气 | 没有变化——氨气在温热时已被赶走；应在加热时检验 |
| 试管中残留 H₂O₂ 后再加酸化 KMnO₄ | KMnO₄ 褪色，并伴有气泡（氧气） |
| 反应停止很久后才检验气体 | 没有结果——气体已经逸散 |
| 试管装得太满 | 溢出 |

其他建议：每个测试用约 1–2 cm 深的溶液；除非题目要求加到同一支试管，否则**每个测试使用一支新试管**；按题目的试剂顺序操作；题目要求静置时要静置。

## 8. 在手机或 iPad 上使用

- **手机**（及其他较窄的窗口）：使用底部标签——**🧪 Lab**（实验台）、**📄 Paper**（试卷）、**📓 Notebook**（笔记）。对话框以底部弹出面板形式显示。
- **iPad 竖屏**：上方是实验台，下方是试卷，无需切换即可边做实验边作答。
- **iPad 横屏／电脑**：左侧是实验台，右侧是试卷和实验笔记。

在 iPad 上写较长答案时，外接键盘会更方便，但并非必需。

## 9. 作答保存在哪里

答案、草稿、自评分数及观察文字开关的设置保存在**本设备的这个浏览器**中（localStorage），不会发送到任何地方。

- 关闭标签页或刷新后仍会保留——但**实验台**不会保留：离开题目再回来会得到一套全新的样品。
- 使用无痕／隐私窗口、清除网站数据，或换用其他浏览器或设备时，内容为空。
- *Try this question again* 会刻意清除该题的答案、笔记和分数。

## 10. 常见问题

**屏幕上的颜色难以判断。** 不同屏幕显示有差异。打开 *Observation text* 阅读文字描述，下次再尝试辨认。

**检验气体时没有反应。** 气体只在生成期间（或加热后的短时间内）存在。重复该步骤并立即检验；检验氨气时要先加热混合物。

**为什么我的结果与监考员结果不同？** 通常是因为用量、加入顺序、未清洗试管或时间不同——监考员严格按题目操作。请对照题目检查你的操作记录。

**答案会自动改分吗？** 不会。你需要对照评分标准自行评分。

**离开后能回到原来的实验台吗？** 不能。写下的答案会保留，但实验台每次都会重新开始。

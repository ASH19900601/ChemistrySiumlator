## 1. 打开程序

由持有仓库的人执行：

```bash
npm install
npm run dev -- --host
```

- 在同一台电脑上打开 <http://localhost:5173>。
- 在同一 Wi-Fi 下的手机或 iPad 上，打开终端显示的 `Network:` 地址（例如 `http://192.168.1.20:5173`）。

任何现代浏览器均可（Chrome、Edge、Safari、Firefox）。

## 2. 选择题目

首页把题目分为两组：

- **Cambridge IGCSE Chemistry 0620 · Paper 5 Practical Test**
- **Cambridge International AS & A Level Chemistry 9701 · Paper 3**

每张卡片显示考试季、总分和对未知物的中性描述（不会透露答案）。点击卡片即可开始。

## 3. 考试界面

| 区域 | 说明 |
|---|---|
| **顶栏** | ← 返回题目列表 · 试卷及题号 · ⏱ 已用时间 · **?** 重播示范 · 🔊 声音开关 · 观察文字开关（*Observation text*）· ⇥ 隐藏／显示试卷（电脑）· 交卷（**Finish**） |
| **实验台** | 按考场实验台样子绘制的工作台（见下文） |
| **试卷／实验笔记**（Question paper / Lab notebook） | 带答题位置的题目；以及所有操作的记录和草稿栏 |

第一次打开题目时，会有一只"虚拟的手"示范主要动作：取试管、用滴管、开燃气、点燃本生灯、加热试管。点击任意位置可跳过；按 **?** 可再看一次。

### 实验台上有什么

| 位置 | 仪器 |
|---|---|
| 试剂架 | 本题的试剂瓶（与机密说明一致），每瓶都配有自己的滴管；石灰水；装在广口瓶里的固体试剂；放在培养皿里的镁带或铝箔 |
| 试管架 | **样品**（如 *solid E*、*FA 7*，通常塞着塞子）和其他试管一起放在试管架上——可以像普通试管一样使用 |
| 台面中间 | 本生灯（含燃气阀和空气孔调节环）、火柴盒、放在漏斗架上的漏斗、蒸馏水洗瓶、废液缸 |
| 前方托盘 | 干净的试管、沸腾管、硬质玻璃试管各一盒；塞子；药匙；红色石蕊试纸、蓝色石蕊试纸和通用指示剂试纸（附比色卡）；木条；滴管（胶头滴管）；焰色测试金属丝；白瓷板 |
| 墙上 | 显示实验台已过时间的时钟 |
| 右前方 | 水槽（用来冲洗试管） |

**实验台上的时间会持续流逝。** 沉淀会沉降、气泡逐渐停止、热试管会冷却、氢氧化亚铁表面会慢慢变棕——隔一会儿再看看试管，就像在真实实验室一样。点击**时钟**可让时间以十倍速度流逝（表圈变成橙色），再点一次恢复正常。题目要求"静置"或等待加热时可以使用。

### 观察文字开关（*Observation text*）

默认关闭。真实考试中没有人告诉你看到了什么，所以平时你只能**看到**仪器本身：颜色、沉淀、气泡、气体、冷凝水、试纸的颜色、火焰的颜色。打开开关后，每个结果会附带简短的文字描述——适合学习术语，或屏幕上颜色难以判断时使用。

## 4. 在实验台上操作

所有操作都和亲手做实验一样：**拿起一样东西，把它带到另一样东西那里。** 没有菜单，也没有按钮。

移动物件有两种方式，可以混用：

- **拖动**——按住物件，移动，松手。适合鼠标和 iPad。
- **点一下，再点一下**——点一下物件把它拿起（它会浮起并轻微上下浮动），再点一下要放到的位置。需要持续进行的动作（倾倒、把试纸放在试管口）则在目标上**按住不放**。点击实验台空白处即可放回物件。在手机上很方便。

拿着物件时，它会起作用的位置会以流动的虚线框标示。

### 试管

- **取干净试管**：点一下托盘上的试管盒（试管会放到试管架下一个空位），或把试管从盒子拖到试管架。
- **移动试管**：把它拖到试管架的另一个位置。
- **塞子**：把塞子从塞子盒拖到试管上；把塞子拖离即可取下。塞着塞子的试管不能加入、倒出或检验任何东西。
- **振荡**：拿着试管时左右快速晃动。
- **倒掉**：把试管拖到**废液缸**（管壁会留下液膜）。**冲洗**：拖到**水槽**。**丢弃**：拖回对应的试管盒（样品不能丢弃）。

### 加入液体

- **倾倒**：把试剂瓶（或试管、洗瓶）拿到试管口上方。它会倾斜，**一直放在那里就一直倒**；移开或松手即停止。试管旁的黄色刻度以厘米显示液面深度，方便像考试一样判断"1 cm 深"或"2 cm 深"。
- **逐滴**：从试剂瓶取出**滴管**（按住红色胶头），放进试管——滴管会停在那里。**每点一下滴管滴一滴**；按住不放则连续滴下。用完后把滴管拿走（拖到任意位置）。"逐滴加入，然后过量"即先逐滴，再从试剂瓶倾倒。
- **蒸馏水**：用洗瓶以同样方式倾倒。
- **石灰水**：先倒进一支干净试管，再把气体通入（见下文）。

### 加入固体

- **药匙**：把药匙带到装有干燥固体的试管（或广口瓶）取一匙；再带过去一次即多取一些。然后把药匙带到另一支试管，把固体倒进去。
- **镁带／铝箔**：从培养皿拖一片到试管。
- **倒出固体**：把装有固体的试管拿到另一支试管上方，与倾倒液体相同。

### 加热

1. 点一下**燃气阀**开气（会听到嘶嘶声）。
2. 从火柴盒拖一根**火柴**到本生灯顶部——灯就会点燃。火柴几秒后会燃尽。
3. 点一下**空气孔调节环**，在蓝色呼呼作响的火焰（空气孔打开，温度高）和黄色火焰（关闭，温度较低）之间切换。
4. 把试管拖到本生灯上：它会被试管夹夹住，悬在火焰上方。
   - **较高位置**（试管底部在火焰尖端）——温和加热液体／缓慢加热固体。
   - **较低位置**（在蓝色火焰中）——加热至沸腾／强热固体。
5. 把试管拖离即停止加热。再点一下燃气阀可关闭本生灯。

注意观察熔化、颜色变化（有些固体热时颜色不同）、试管口附近的冷凝水、气泡、有色气体，以及液体被蒸干。强热固体最好使用**硬质玻璃试管**。塞着塞子的试管不能加热——塞子会被冲出。

### 检验气体

气体只在生成期间（或加热后的短时间内）存在，所以要**立即**检验。

- **石蕊／通用指示剂试纸**：从试纸本取一条。要**润湿**试纸，把它放在洗瓶嘴处片刻。然后把它放在**试管口**，直到颜色变化。干燥的试纸对气体没有反应。（把试纸浸入液体检验的是**溶液**，而不是气体。）用过的试纸会放在白瓷板上，方便再看。
- **木条**：从木条盒取一根，放进火焰点燃。把**燃着的木条**放在试管口。要得到**带火星的木条**，把燃着的木条左右快速挥动（或在拿起状态下点一下它）。
- **石灰水检验**：取一支**胶头滴管**，放在反应试管口吸入气体，再把滴管尖端伸进装有石灰水的试管，把气体通入。

### 其他测试

- **焰色测试**：取焰色测试金属丝，把金属圈蘸上固体或溶液，再放进**蓝色**火焰。火焰会呈现颜色几秒；把金属丝留在火焰中即可烧干净。
- **pH**：把一条通用指示剂试纸浸入溶液，与试纸本上的比色卡对比。
- **过滤**：把漏斗从漏斗架拖到试管架上的一支试管上，再把混合物倒进漏斗。滤液流进试管，滤渣留在滤纸上。也可以用同样方法把其他试剂倒过滤渣。把漏斗拖回漏斗架即可取下，拖进废液缸则丢弃滤纸。

## 5. 填写答案

打开**试卷**（电脑：右侧的 *Question paper* 标签；手机：底部的 **📄 Paper**）。试卷沿用原题版式：引言，然后是各小题、分值及答题位置——答题线、测试与观察表格，或带标签的填空栏。

- 按评分标准的写法作答：同时写出颜色**和**状态（例如 "white precipitate, soluble in excess giving a colourless solution"），以及 "effervescence"、"damp red litmus turns blue" 等。
- 记录你**看到**的现象，而不是你预期的现象。如果在实验台上操作出错，用一支干净的试管重做。
- **实验笔记**（Lab notebook）按时间和试管列出每一步操作；其他内容可写在 *Rough notes*（草稿）栏。

答案会在输入时自动保存。

## 6. 交卷与自我评分

点击 **Finish**（顶栏或试卷底部）并确认。自我评分页面会为每一小题显示：

- 题目（点击 *Question* 展开）；
- **你的答案**（Your answer）；
- 官方**评分标准**（Mark scheme）；
- **监考员结果（模拟）**（Supervisor's results (simulation)）——严格按题目步骤操作时本模拟产生的结果，相当于真实考试随答卷寄出的监考员报告；
- 一排分数按钮（0 至满分），用来给自己打分。

总分显示在右上角。页面底部可查看**未知物是什么**（来自机密说明），以及**你在实验室中的全部操作**及每一步的观察——可与自己写的答案对照。

之后可选择 **Try this question again**（清除本题的答案、笔记和分数，并重新开始一个新的实验台）或 **Choose another question**（选择其他题目）。

请诚实评分：只有当你的答案包含评分标准中的要点时才给分。如果监考员结果与你的观察不同，请在操作记录中找出你的步骤与题目不同之处。

## 7. 规范操作——以及不规范会怎样

引擎只知道每支试管里有什么，所以典型的错误操作会得到与真实实验室相同的结果：

| 如果你…… | 会看到…… |
|---|---|
| 加 AgNO₃ 前用稀 **HCl** 酸化 | 即使样品不含氯离子也出现白色沉淀（AgCl）——应使用稀**硝酸** |
| 对碳酸盐加 Ba²⁺ 或 Ag⁺ 前忘记酸化 | 加硝酸钡出现白色沉淀（误判为"硫酸根"），加硝酸银出现沉淀 |
| 重用未清洗的试管 | 上一次测试的残留，例如氯离子令 AgNO₃ 变浑浊 |
| 用自来水代替蒸馏水 | 加硝酸银时略显浑浊 |
| 向已酸化的溶液加 NaOH | 最初几滴只是中和酸，沉淀稍后才出现 |
| 一次倒入大量过量 NaOH（例如对 Al³⁺ 或 Zn²⁺） | 沉淀只出现一瞬间，甚至看不到——应**逐滴**加入 |
| 试管冷却后才检验氨气 | 没有变化——氨气在温热时已被赶走；应在加热时检验 |
| 试管中残留 H₂O₂ 后再加酸化 KMnO₄ | KMnO₄ 褪色，并伴有气泡（氧气） |
| 反应停止很久后才检验气体 | 没有结果——气体已经逸散 |
| 把**干燥**的石蕊试纸放在试管口 | 没有变化——要先润湿 |
| 把红色石蕊试纸浸入碱性混合物，而不是放在试管口 | 无论有没有放出氨气都会变蓝——这个测试检验的是**气体** |
| 想向塞着塞子的样品加东西 | 加不进去——先取下塞子 |
| 加热塞着塞子的试管 | 塞子被冲出 |
| 把试管放到未点燃的本生灯上，或使用黄色火焰 | 几乎不加热 |
| 试管装得太满 | 溢出 |

其他建议：每个测试用约 1–2 cm 深的溶液；除非题目要求加到同一支试管，否则**每个测试使用一支新试管**；按题目的试剂顺序操作；题目要求静置时要静置。

## 8. 在手机或 iPad 上使用

- **手机**（及其他较窄的窗口）：使用底部标签——**🧪 Lab**（实验台）、**📄 Paper**（试卷）、**📓 Notebook**（笔记）。实验台会占满屏幕高度并可**左右滚动**：在实验台空白处滑动即可查看其他部分；把物件拖到边缘时实验台会自动滚动。小屏幕上"点一下，再点一下"往往比拖动更方便。
- **iPad 竖屏**：上方是实验台，下方是试卷，无需切换即可边做实验边作答。
- **iPad 横屏／电脑**：左侧是实验台，右侧是试卷和实验笔记。按顶栏的 **⇥** 可隐藏试卷，让实验台更大。

在 iPad 上写较长答案时，外接键盘会更方便，但并非必需。

## 9. 作答保存在哪里

答案、草稿、自评分数及各项设置（观察文字、声音、是否已看过示范）保存在**本设备的这个浏览器**中（localStorage），不会发送到任何地方。

- 关闭标签页或刷新后仍会保留——但**实验台**不会保留：离开题目再回来会得到一套全新的样品。
- 使用无痕／隐私窗口、清除网站数据，或换用其他浏览器或设备时，内容为空。
- *Try this question again* 会刻意清除该题的答案、笔记和分数。

## 10. 常见问题

**屏幕上的颜色难以判断。** 不同屏幕显示有差异。打开 *Observation text* 阅读文字描述，下次再尝试辨认。

**检验气体时没有反应。** 气体只在生成期间（或加热后的短时间内）存在。重复该步骤并立即检验；检验氨气时要先加热混合物。石蕊和指示剂试纸必须是湿润的，试管也不能塞着塞子。

**把物件带到试管那里却没有反应。** 留意虚线框：它标示物件会起作用的位置。塞着塞子的试管只能取下塞子。如果手上拿着其他物件，请先放下（点击实验台空白处）。

**我想撤销操作。** 和真实实验室一样，不能撤销。把试管倒进废液缸，在水槽冲洗，再用干净的试管重做。

**等待时间太长。** 点击墙上的时钟，让时间以十倍速度流逝。

**为什么我的结果与监考员结果不同？** 通常是因为用量、加入顺序、未清洗试管或时间不同——监考员严格按题目操作。请对照题目检查你的操作记录。

**答案会自动改分吗？** 不会。你需要对照评分标准自行评分。

**离开后能回到原来的实验台吗？** 不能。写下的答案会保留，但实验台每次都会重新开始。

# 使用问题复现与修复记录（任务一）

基线提交：`22f9712`。以下是 23 个分别可复现的使用问题；部分问题共享状态管理或温度传递修复，并非声称有 23 个独立根因。没有把原本通过的防回归检查计作已发现问题。

温度混合是半定量模型，不声称包含混合热、玻璃热容或精确量热。气体采样也是有限物质量近似。

## 第二阶段：手机端操作

- 手势画面通过 `requestAnimationFrame` 合并刷新，不再等化学时钟每 100ms 更新才移动。
- 实验台统一处理触摸：器材拖动不会被浏览器误判为滚动；空白处拖动可平移视图。
- 同时只接受一根主手指，正确处理触摸取消、失去捕获和窗口失焦。
- 靠近边缘并停住时仍持续滚动，并在滚动后重新计算器材位置；横向和纵向均可操作。
- 增加试剂、试管、加热、工具、清洗区域导航，以及缩放、全景和放回。
- 触屏默认放大器材并扩大命中区域；工具栏、评分和主要触摸按钮至少 44px。
- 输入字号至少 16px，避免 iPhone 输入时自动缩放；试题表格与字段适应窄屏。
- 切到试卷/笔记时释放手中器材；页面进入后台时暂停化学时钟，防止隐藏页面继续误操作。
- 试卷、笔记和静态场景减少重复渲染；支持减少动画偏好。

浏览器测试使用真实 Chromium 触摸事件，覆盖建管、点击倒液、放回、边缘拖动、取消、多指干扰、分页输入保持、320–430px 手机宽度、横屏和 iPad 尺寸。桌面检查保留。没有声称已在实体 iPhone 或 Safari 上测试。

## 任务二补充发现

新增 AS Q2 的原评分标准回归发现：锰酸根在浓水提取液中被模型设为半秒歧化，导致应该观察到绿色时立即变紫。已区分浓、稀、中性、酸性及强碱条件；同时保留原 `9701_w24_34` 稀水提取液呈紫色的检查。时间和浓度阈值用于半定量模拟并注明来源观察窗口，不声称精确动力学常数。新增的强酸反应测试验证锰酸根确实转化为高锰酸根和二氧化锰。

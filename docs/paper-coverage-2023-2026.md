原资料包：`dropbox_downloads/Chemistry_Qualitative_Practicals_2001-2026.zip`（Git LFS，130824313 字节）。

SHA-256：`4b2e3266cc666b68ee1aa092fb07ea7edd68b72c5d3b0a45f92e35251dab678c`。

`tools/prepare_past_papers.py` 验证资料包，复制原始 PDF，生成保留原版表格及化学式的图像和 `src/papers/archive-data.ts`。清单保留原始来源 URL、页码和每份 PDF 的 SHA-256。不会用关键词出现次数推断样品成分，也不会合成缺失题目或评分标准。

```sh
git lfs install --local
git lfs pull --include=dropbox_downloads/Chemistry_Qualitative_Practicals_2001-2026.zip
python3 -m venv ../.chemistry-paper-tools
. ../.chemistry-paper-tools/bin/activate
python -m pip install -r tools/requirements.txt
npm ci
npm run prepare:papers
npm run check:papers
npm test
npm run test:browser
npm run build
```

生成的 `public/past-papers/` 约 104 MiB，受 Git 忽略，必须由脚本生成；构建前会检查资料。重复生成已验证。构建输出自带资料，读取已导入原题不依赖外网。Chromium 测试可用 `CHROMIUM_PATH` 指定系统浏览器；否则安装 Playwright 浏览器（`npx playwright install chromium`）。
